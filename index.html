Beyond Our Kind VPS Archives

A personal archive utility operated by the owner of the Travisaggie04 GitHub account. It transfers selected development-worker results between the owner's private server and the owner's Google Drive.

Purpose and access

The utility uses rclone for file transfers. An owner-authorized AI assistant may operate the archive workflow. It requests Google's drive.file permission to create archive files and access files created by, or explicitly made available to, this app.

The workflow uploads selected results, downloads a fresh copy, checks file integrity and tests restoration. It does not need access to the owner's entire Google Drive. This information page does not contain archives or provide access to them.

Personal use

This utility is for the account owner's own development work. It is not a public file-hosting service or an invitation for other people to connect their Google accounts.

Read the privacy policy. For support, contact the operator through the user-support address shown on Google's consent screen. Do not post private files or credentials in a public issue or comment.
